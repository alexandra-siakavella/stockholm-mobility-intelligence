# Stockholm Mobility Intelligence Platform

An end-to-end data engineering and machine learning platform for analysing and forecasting mobility demand in Stockholm.

## Project Status

🚧 In development

## Objectives

- Build a reliable data ingestion pipeline
- Implement a medallion-style data architecture
- Transform and model mobility data
- Implement automated data-quality checks
- Build demand forecasting models
- Detect mobility demand anomalies
- Create business-facing analytics
- Implement CI/CD and reproducible development

## Technology Stack

- Python
- SQL
- PySpark
- PostgreSQL
- dbt
- Apache Airflow
- Docker
- GitHub Actions
- Machine Learning
- Power BI
